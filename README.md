# CISC 121 Assignment 1
Completing 5 Problem Sets

**What to Do**

    1. Select any five problems from the table.

    2. Write the pseudocode by hand for each problem. Take a clear photo, or a screenshot if you wrote it on a tablet.

    3. Write your Python solution for each problem.

    4. Upload your pseudocode and Python code to your GitHub repository.


**What to Upload**

Submit one PDF report. For each problem, include:

    1. A photo or screenshot of your handwritten pseudocode.

    2. Your Python code with appropriate comments.

    3. Citations for any AI tools or open-source resources you used.

    4. A link to your AI chat/conversation and a link to your GitHub repository.

*Important: Submissions without proper citations and the required links will be considered incomplete and may be voided.*
